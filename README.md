背景：三电极的相关知识

三电极=工作电极WE+参比电极RE+对电极CE

WE为电化学反应的电极，信号在此产生，且电化学检测对电极的修饰也常在WE上进行。EG：玻碳电极

RE为电位标尺，用于检测电位，应无电流通过，常用Ag/AgCl(饱和KCl)作为参比电极

CE完善电流回路，电流从WE到CE形成一个完整的回路后方可检测相应的电化学指标，要求导电性好，惰性。EG:铂丝电极，玻片电极，石墨棒。
