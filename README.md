# 背景：三电极的相关知识

三电极=工作电极WE+参比电极RE+对电极CE

WE为电化学反应的电极，信号在此产生，且电化学检测对电极的修饰也常在WE上进行。EG：玻碳电极

RE为电位标尺，用于检测电位，应无电流通过，常用Ag/AgCl(饱和KCl)作为参比电极

CE完善电流回路，电流从WE到CE形成一个完整的回路后方可检测相应的电化学指标，要求导电性好，惰性。EG:铂丝电极，玻片电极，石墨棒。

# 构建思路：

对于WE和CE，一般都能找到较为合适且便宜的部件，但对于RE，其功能的特殊性决定其费用要高于其余两个电极。作者之前尝试过使用使用陶瓷滤芯镶嵌在细玻璃管底部，购买银丝使用HCl氯化置于管内，配置3 M KCl溶液填入管内，手动将银丝与导线焊接，并使用热熔胶封顶，制作了第一支自制RE，通过使用万用表检测与商用RE的电势差，结果大致为15mv左右，可以使用，但后来在实验室中离奇消失，也没心情再重新制作了。

SPE丝网印刷电极将三电极集成到一张小小的纸片之上，小巧轻便，且价格便宜，比较适合用作个人实验性的探究。需要注意SPE本身寿命不长，无法长时间使用。

<img width="4096" height="3072" alt="IMG_20261104_192414" src="https://github.com/user-attachments/assets/c6bca32e-f956-4bcb-860c-f6c1151f9cdb" />

具体的构建思路是将WE的电压钳制在0V（之后的电压都是相对于GND），通过RE检测溶液体系的电位，通过CE控制溶液体系的电位。

具体来说，若我想要让WE带+1V的电压（想对于溶液体系），此时RE检测到溶液体系电位为0V，但WE本身电位被钳制在0V，因此需要改变溶液体系的电位，使其带-1V的电位，此时WE（0V）想对于溶液体系（-1V）就带了+1V的电压。

对于溶液的电位的控制，通过CE来实现。当我想让溶液的电位增高，我就通过CE抽取溶液中的电子，使其带正电，达到我想要的水平后就停止。当我想要让溶液的电位带负电，就通过CE往溶液中灌电子，其电位自然也就下降了。

值得注意的是，化学中不能真的把电子灌入溶液，溶液中需要有可以氧化还原的物质，如Fe2+/Fe3+用于接收、释放电子。

想象一个场景，当我往溶液体系中施加一个变化的电压（电压从-1V到0V匀速变化），此时溶液应该不断的在释放电子出体系好让电压变高，如果体系中的Fe2+比较多，那么这个过程完成的时间应该比较快（在其中的一段时间比较快，因为Fe2+可以较为容易的释放电子），又因为单位时间内电子的变化数量宏观上表现为电流的高低，在电压匀速变化的过程中，该含Fe2+较多的溶液应该会有一段线呈现出I峰值比较高，而另一个含Fe2+比较少的体系该段线呈现的I峰值应该比较低，这也就是电化学定量的原理之一。

以上只是非常粗浅的描述，而正确的描述需要用上离子的扩散控制、欧姆降、双电层空间分布、离子迁移、Randles–Sevcik 方程等等理论，在此不加赘述。



# V1.0 电流定性检测阶段

器件核心元件以树莓派PICO作为核心绘制器，INA1115作为电压检测器（ADS），MCP4725作为电压产生器（DAC），使用HW-131作为外部电源模块（个人对PICO的供电能力和供电稳定性表示质疑），使用OP297作为运放部件，使用AD825TIA模块作为微小电流检测器（此处也可以自行搭建运放，但难度较大）

对于原SAKANA项目进行了删改，首先使用AD825模块代替了TIA运放功能和INA219的电压检测功能，因为在实测中发现它们的稳定性不好，且不好操作。而AD825模块作为反向跨阻放大器，其本身便可以将微量电流转化为反向放大的可测量大电压，简化了电路，增强了可维护性。

而且针对SAKANA项目单使用PICO供电，发现PICO供电能力优先，且供电电压不稳，引入外部电源，将PICO的GND与外部电源的GND通过一根短导线相连（只连接一次）

# V2.0 电流定量检测阶段

对于AD825输出的电压，其可将微量电流放大10万倍，实现微小信号的放大，但是其输出的为双极性电压，示波器可以轻松的接收，但无法很好的定量，而普通的ADC（如ADS1115）又只能接收正电压（相对于GND）。这成了解决电流定量检测的第一个问题。

对于这个问题，存在多种可行的解决方案，如抬升电平，将电平缩放至某个范围，利用差分电压检测等等，但这些方法需要一定的模拟电子技术基础，作为电化学检测出身，这些解决方案比较，麻烦，因此我选择了直接购买现成的双极性ADC模块，选用模块为ADS8688
